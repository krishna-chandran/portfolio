CINCINNATI — The spindle-health work needed a face. A web application took the live vibration path and put a score from 0 to 100 on a browser, so a supervisor did not have to stand in the chips.
<!--more-->

Python and Flask carried the experimental models into something a floor could leave running. It is the same 2018 Mazak project as the classification work, shown at IMTS, written up by the university.
